How it works

Private by design.

This is a static client-side replica. Your API key and images never touch a server we control — requests go straight from your browser to your image-model provider, and the key is kept in this browser’s local storage only.

  1. 1 Add your image-model API key (the “API key” button, top right).
  2. 2 Choose a mode and drop a sketch, garment or moodboard.
  3. 3 Describe the material, finish or scene you want.
  4. 4 Generate, download, and feed the result back in to iterate.

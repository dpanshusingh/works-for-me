What I look for

Security

  • Leaked secrets and keys
  • Auth and authorization gaps
  • Injection, XSS, unsafe uploads
  • Vulnerable or invented dependencies

Reliability

  • Missing error handling and retries
  • Race conditions, data-loss paths
  • Missing input validation
  • Test coverage that matters

Performance and cost

  • N+1 queries, missing indexes
  • Unbounded loops and memory use
  • Cloud spend that will balloon

AI-code smells

  • Duplicated and dead logic
  • Code that looks right but is wrong
  • Inconsistent patterns across files

  2. You grant read-only access (GitHub or a zip). I sign an NDA first if you ask.

What a finding looks like

[HIGH] Payment webhook accepts unsigned requests Where: api/webhooks/stripe.py:42 Why it matters: anyone who finds the URL can mark orders as paid. Fix: verify the signature header before parsing the body (about 20 lines). Effort: 1 hour. Risk of fix: low. [MED] Orders list runs one query per row Where: services/orders.py:88 Why it matters: page load time grows linearly; 10k orders will time out. Fix: join or batch-load line items. Effort: 2 hours. [LOW] Three near-identical date helpers Where: utils/dates.py, ui/format.js, api/helpers.py Fix: consolidate into one module.
